# GameForge — быстрые мини-игры для хакатона Билайна

Короткий запрос → новая HTML5-мини-игра → быстрая проверка → игра в макете телефона.
Дальше — небольшие правки существующей игры, сохранение истории, публикация и ремикс.

**Состояние на 18 октября 2026 года:** конкурсный проект очищен для новой реализации.
Здесь находятся согласованные требования и план; новый backend/frontend ещё не написан.
Прежняя запущенная установка остановлена. Старые команды запуска здесь больше не действуют.

Главный приоритет — скорость получения **рабочей** игры. Первичный ориентир команды:
медиана до 30 секунд на создание и до 10 секунд на небольшую правку; это цели для
измерений, не обещание производительности и не числа из регламента.

Нормальный путь содержит один модельный запрос и короткую браузерную проверку.
Модель генерирует механику, а не выбирает готовую зашитую игру. Правки возвращаются
патчами к сохранённой версии. Пересборка скачиваемого HTML не означает повторной
генерации всего кода нейросетью.

Целевой стек: Django/DRF, PostgreSQL 18+, Celery, Redis; React, TypeScript, SCSS.
Сначала — локальные испытания через установленный Codex с пользовательским входом.
Затем — сменный API-коннектор к модели на физическом сервере с vLLM.
