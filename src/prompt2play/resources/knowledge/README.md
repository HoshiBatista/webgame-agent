# Conditional generation lessons

`lessons.json` contains concise versioned guidance derived from the donor, with
release/path/source hash and a named regression test. The selector matches
declared mechanics, selected capabilities or recorded finding codes. Irrelevant
card, audio and save rules are absent from a simple grid puzzle context.

Historical logs remain evidence. These entries do not constitute model training,
instructions retrieved from arbitrary logs, or a reason to include entire prior
conversations in every request. A behavior-changing lesson update requires a new
version and fixed-suite comparison.
