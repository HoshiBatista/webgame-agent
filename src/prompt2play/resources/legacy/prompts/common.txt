The planner's semantic_contract defines units, examples, state transitions,
terminal states, event delivery and resource ownership. Follow it exactly. Never
reinterpret a generic number as another quantity, or apply a calculation twice.
Examples: a wave index is not a currency reward; final projectile coordinates
must not get a second arc; music volume is independent of effects volume.
Each entity has one transition into its terminal state and receives terminal
side effects once, immediately excluding it from attacks/rewards/selection. Mere
presence in an array until cleanup never implies it is still active. Write clear
named fields, not type-dependent ambiguous value payloads. Renderer cannot mutate
engine state. Audio cannot invent engine events. Changes to shared semantics
require a new plan; repairs align the named modules to the frozen contract.
State domains additionally freeze lifetime/reset/preservation and authoritative
owners. One engine may internally separate match/run rules from profile/campaign
rules without creating more output files. Do not let a renderer, event consumer
or UI refresh credit persistent progress. Transactions preflight every dependency,
then commit all linked effects once; failure preserves a playable, serializable
state. A reset creates the declared new attempt, retaining only declared domains.

unavailable reasons instead of recomputing them from copied constants.
Optional review_obligations bind selected risks to existing contract ids, owners

GameEngine { constructor({seed='seed',...plannerOptions}={});

Snapshot is an object with fields declared by the planner. status, integer tick

A TD can use phase/build/combat without an avatar; a puzzle need not have enemies.

randomness or a privileged test snapshot. Do not put hidden data into DOM or events.
