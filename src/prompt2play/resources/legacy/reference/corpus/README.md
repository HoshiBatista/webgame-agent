# Регрессионный корпус разных жанров

Эти исходники — **доверенные записанные примеры для тестов разработчика**.
Они не подключаются к провайдеру, не импортируются как новые генерации и никогда
не подставляются вместо промпта пользователя. Это не система шаблонов жанров.

- `emberwatch`: полная ранее созданная tower defence 1.0.1, включая Canvas,
  музыку и интерфейс. `provenance.json` фиксирует исходные SHA-256 и небольшую
  адаптацию интерфейса времени/стилей для сборщика Game Forge. Оригинальная игра
  и её публикация не изменены.
- `lamps`: маленькая пошаговая головоломка без `player`, без `wait` и без
  автоматического изменения правил от течения времени.
- `runner`: маленький платформер с фиксированным шагом, прыжком, проигрышем
  без прыжка, победой при правильном действии и замораживанием времени на паузе.
- `camp`: полный проверенный рогалик 2.0.1 с лагерем, NPC, заданиями, зданиями,
  постоянным и временным прогрессом. Шесть оригинальных модулей сохранены
  побайтно, адаптация к четырём файлам воспроизводима и связана с provenance.
  Подробности, зависимости и команды — в [camp/README.md](camp/README.md).
- `durak`: полный проверенный подкидной дурак 1.0.1 на 2–4 участников с исходным
  DOM/SVG-интерфейсом, анимациями, звуками, ботами и сохранениями. Добавляет
  проверку скрытых наблюдений, добровольных решений человека, очередности
  действий, повторного монтажа и асинхронных ресурсов. Адаптация и границы
  свидетельств — в [durak/README.md](durak/README.md).

`python scripts/test_corpus.py` подменяет **только модель** явно названным
RecordedCorpusProvider и проводит каждый пример через настоящий LangGraph,
сборщик, статический валидатор и привязку отчёта к артефакту. Это проверяет
совместимость конвейера. Это **не живой результат генерации**.

`node reference/corpus/run.cjs` исполняет только пять жёстко перечисленных
доверенных движка из этого каталога. Используется настоящий интерпретатор QA
сценариев, но адаптер обращается к движку, а не браузерному DOM. Дополнительно
Emberwatch проходит кампанию законными действиями двух стратегий. Выигрыш,
поражение, учёт врагов и сохранение проверяются без подмены ресурсов или HP.
DOM, Canvas, реальные звуковые устройства и WebView этим тестом не проверяются.
Durak дополнительно проходит 36 полных партий через исходные правила и ботов,
включая добровольное взятие при доступной защите; все точные 36 идентичностей
карт проверяются независимым привилегированным oracle после каждого хода.
Отдельный `node reference/corpus/camp/qa/run_ui.cjs` исполняет точный HTML из
настоящего сборщика в LinkeDOM с CPU Canvas и явной моделью хранилища. Он
проверяет кампанию через её собственный UI, включая отказ записи/чтения и
сочетание отложенного импорта с изменившимся общим сохранением. Он также
не является браузерным тестом.
`node reference/corpus/durak/qa/run_ui.cjs` исполняет восемь декларативных и
пять интеграционных проверок в точном HTML из настоящего сборщика, используя
LinkeDOM и явные модели фокуса, таймеров, хранилища и Web Audio. Искусственный
Canvas этой DOM-игре не добавляется. Это также отдельное свидетельство
совместимости, а не живой браузер или результат новой генерации.
Отдельный четырнадцатый случай проверяет общий интерфейс того же точного
аудиомодуля: независимые громкости, подавление повторов, ограничение голосов
и освобождение узлов с сохранением контекста, принадлежащего UI.

Запуск произвольного сгенерированного JavaScript в Node на хосте запрещён:
производственный runtime Game Forge исполняет его только в изолированном Docker.
Данные `qa_scenarios` ограничены закрытым языком команд, без `eval` и произвольных
выражений. Фиксированные тесты совместимости и живые оценки качества следует
учитывать раздельно.
