# Эталон: «Пепельный свод»

Это существующая игра из исходного разговора, а не результат нового запроса к
модели. При импорте она обязательно отмечается как **эталон**. Генератор не должен
возвращать её вместо выполнения произвольного промпта.

`Ashen_Vault.html` содержит все правила, процедурную графику, анимацию, интерфейс,
звуковые эффекты и 96-секундную музыку в одном скрипте. Внешних ассетов нет.

Файлы `engine.js`, `renderer.js`, `music.js`, `ui.js` показывают реальную структуру,
из которой собран HTML. Имена классов здесь исторические (`AshenEngine`,
`AshenRenderer`, `AshenMusic`, `AshenSound`); это примеры инженерных решений, а не
готовые модули контракта Game Forge. Не переименовывайте их механически при
создании новой игры. Для новой игры сначала проектируется собственное состояние.

## Как читать примеры

- Механика: явное состояние, воспроизводимая случайность, действия, события,
  сохранение и загрузка, победа и поражение.
- Отрисовка: Canvas, отдельное визуальное состояние, освещение и видимость,
  интерполяция координат. Отрисовка не меняет игровые правила.
- Анимация: конечности и предметы двигаются относительно суставов, направление
  определяет вид спереди/сбоку/сзади, ходьба включается при реальном перемещении.
- Звук: один AudioContext после действия пользователя, отдельные уровни музыки
  и эффектов, небольшие кешируемые сэмплы, планирование по звуковым часам,
  освобождение источников, остановка при скрытии страницы.
- Интерфейс: понятные команды, состояние паузы, клавиатура и сенсорное управление,
  настройки звука и движения, защита сохранения от неудачного импорта.

Файлы `test_*` и `qa_walk.cjs` сохранены как свидетельства использованных проверок.
Они не являются универсальными тестами для всех жанров. Некоторые требуют
`@napi-rs/canvas` и исторический путь runtime; приложение-генератор их автоматически
не запускает и не выдаёт их результат за проверку новой игры.

Проверки оригинала выполнялись в Node и CPU Canvas. В исходной среде не были
доступны проверка CSS в настоящем браузере, WebView и прослушивание через
браузерный аудиодвижок. Проверочный сухой музыкальный микс не включал реальный
браузерный ревербератор и компрессор.
