# Улучшение генерации: P6–P8, ревью C

Дата: 27.10.2026. Ветка `mini-games`, основание Git `815f2b2` и незакоммиченная
поставка P0–P5. Реализованы P6–P8 из [согласованного плана](generation-improvement-plan-2026-10-27.ru.md).
Это локальная реализация. Рабочая БД, облако, Codex Worker и GPU не изменялись.
Модельных вызовов — **0**. Тестовые ответы не являются измерением качества Sol/27B.

## P6. Числовая анимация без шаблонов игр

Добавлен доверенный `GameForgeMotion` v1: `create`, `sample`, `advance`, `cancel`,
`reset`, `inspect`; единица времени — секунда. Значение считается от постоянного
начала, время ограничено длительностью, easing может выходить за диапазон для
отскока. Нулевая длительность, длинная пауза, смена цели, отмена, очистка callbacks
и однократное completion имеют регрессии. Неконечные числа отклоняются.
Уменьшенное движение сразу показывает конечное положение, сохраняя время
completion; игровые правила не должны зависеть от косметических callbacks.

Compact получает `api.motion`, full явно подключает `gf-motion-v1.js` перед своим
модулем. Bundler вставляет локальные проверенные байты в offline HTML. Каталог
версии/hash закрепляется в Run до отправки; Revision хранит использованные helpers.
Модель не может заменить библиотеку. Recheck/preview читают сохранённый HTML,
не пересобирают его новой библиотекой. Для скруглений рекомендуется native Canvas
`roundRect`; отдельного fallback или каталога игровых жанров нет.

Числовые тесты и настоящие снимки отличают ошибочное накопление сдвига от
интерполяции, а смешанные x/y кривой — от стандартного скругления. Это очищенные
синтетические примеры класса ошибки, не точный replay приватной игры прошлого пилота.
Исправность инструмента не доказывает, что модель воспользуется им правильно.

## P7. Один необязательный цикл оформления Pro

Флаг `GAMEFORGE_PRO_VISUAL_REVIEW_ENABLED=1` применяется к новым Pro create Run.
По умолчанию **выключен**. Значение и состояние сохраняются при продолжении;
проверка без модели не запускает визуальный вызов. Lite не переключается в этот путь.

После успешных игровых проверок валидатор повторяет прошедший мобильный маршрут
в обычном времени: начальный mobile, четыре кадра вокруг последнего измеряемого
ввода, начальный desktop. Сохраняются маршрут, действие, размеры, реальные времена,
artifact hash и среда; в запросе добавляются ID/identity точного отчёта. Съёмка
использует ту же изоляцию: отдельный процесс браузера, opaque iframe, CSP и запрет
сети. При отсутствии маршрута или его невоспроизводимости съёмка пропускается.
Она не меняет исходный игровой verdict. Watchdog получает отдельные 45 секунд.

Исходные JPEG (до 256 КиБ каждый) остаются приватными. Модели отправляется одна
контактная таблица 1200×680, не более 512 КиБ. Pillow декодирует реальные пиксели,
проверяет формат, размеры и предел 2 млн пикселей; сигнатуры PNG недостаточно.
Hash каждого кадра, метаданные маршрута, время, актуальность отчёта и hash таблицы
проверяются перед вызовом и при применении ответа. Таблица уменьшает изображения:
по её мелкому тексту нельзя автоматически заключать о нечитаемости исходной игры.
Времена снимков не являются измерением FPS.

`visual_review` возвращает только замечания: конкретный дефект, подозрение,
предпочтение либо `no_change`. Конкретное замечание должно ссылаться на кадры,
замороженное требование и редактируемый файл. Предпочтения, выдуманные кадры,
чужие требования и замечания к доверенному runtime не разрешают правку.
Замечания модели остаются гипотезами, не новым игровым hard gate.

Допускается максимум один `visual_patch`, до шести ограниченных точных замен,
только в разрешённых файлах. Compact меняет только `game.js`, сохраняя предел
12 КиБ, runtime и manifest. Full сохраняет остальные файлы. Checks, обещания,
название и design наследуются; diff правки сохраняется. После неё повторяются
неизменные игровые критерии и съёмка. Регрессия или отсутствие повторных кадров
возвращает исходный проверенный кандидат. Второй цикл автоматически не запускается.

Вызовы занимают общий лимит 4 без plan / 5 с plan; меньший пользовательский лимит
и срок приоритетны. До review нужно место для обоих шагов. Исчерпание допуска,
отказ, некорректный ответ или недостаточный пакет сохраняют проверенную игру.
Отмена останавливает применение; неизвестный исход сохраняет liability и кандидат,
не повторяя вызов. Сбой между receipt и применением восстанавливается без второй
отправки и без второй копии ревизии. Оба Codex-транспорта передают одинаковую схему
и картинку; доступ к shell, файлам хоста и произвольному браузеру не добавлен.

## P8. Версии, данные и выпуск

Одна целевая линия: pipeline **9**, check policy **3**, compact runtime **2**,
planning **2**, manifest **1**, presentation **1**, motion helper **1**, visual **1**.
P4–P8 ещё не выкладывались этой сессией; нового номера поверх этой линии нет.
Существующие лимиты Lite/CLI и два одновременных remote Pro остаются прежними.

Миграция 0016 добавляет каталог/manifest helpers, приватные кадры и состояние
визуального цикла. Историческим Run не присваивается нынешний каталог задним числом.
0017 разрешает публикации хранить состояние недоступности без игровой ревизии.
Структурные миграции сами не удаляют игры и не переписывают старые hashes/receipts.

`retire_games` сначала показывает inventory. `--apply` теперь требует новый
`--backup /private/path/file.json`: файл создаётся исключительно с правами 0600,
сериализует исходники/публикации, отчёты проверок и относящиеся Run/Invocation, синхронизируется
на диск до удаления. Существующий путь и ошибка записи запрещают удаление.
Неизвестный расход сохраняется в БД; активный Run или reserved/sent блокирует очистку.
После удаления несовместимого артефакта публикация остаётся маркером недоступности.
Публичные endpoints и ранее выданные preview-ссылки возвращают HTTP 410, а список
публикаций не показывает неподдерживаемые игры. Ремикс не создаёт чат-замену.

Порядок отдельного выпуска оператором:

1. Закрыть новые отправки, дождаться завершения Run и получения sent receipts;
   отдельно учесть unknown. Сохранить полный проверенный backup PostgreSQL.
2. Обновить зависимости приложения (добавлен Pillow), пересобрать валидатор;
   применить миграции 0015–0017 и перезапустить процессы при закрытом допуске.
3. Проверить `manage.py retire_games`; при реальной несовместимости выполнить
   `manage.py retire_games --apply --backup /private/path/retired-unique.json`.
   Файл содержит приватные данные: не помещать его в Git или web/static.
4. Проверить health, каталог Codex, приёмку старых receipts, доступность старых
   публикаций и локальные регрессии. Возобновить допуск. Оба экспериментальных
   флага оставить выключенными до отдельно согласованного пилота.

Эти действия на рабочих установках в данной сессии **не выполнялись**.

## Ревью C: найдено и исправлено

- Нативная съёмка первоначально включала Playwright service-worker shim, который
  выбрасывает ошибку на opaque sandbox origin. Убрана только эта инъекция;
  service workers запрещены самим origin, сетевые ограничения сохранены.
- Визуальная правка могла пройти игровые тесты при несостоявшейся повторной съёмке.
  Теперь возвращается исходная версия; добавлена отдельная регрессия.
- Compact должен повторно сверять закреплённый helper перед упаковкой и запрещать
  визуальной правке доступ к своей оболочке/расширение модуля. Обе границы проверены.
- Устаревший отчёт, подмена кадра и изображение с правильной сигнатурой, но неверными
  байтами должны отклоняться до отправки. Добавлены декодирование и повторные привязки.
- Фильтр сообщений после визуального цикла исключал также ответы без ключа operation.
  Восстановлено сохранение сообщения; текст отклонённого visual patch не становится
  финальным сообщением принятой исходной версии. Diff успешной правки сохраняется.

- Резервная копия удаления должна включать CheckReport: они каскадно удаляются
  вместе с ревизией. Добавлены сами отчёты и проверка сохранения исторических фактов.

- Подключение helper не должно скрывать единственный игровой JS-модуль от ремонта.
  Доверенная библиотека исключена также из подсчёта игровых модулей; при двух
  настоящих модулях неоднозначность по-прежнему запрещает произвольную замену.
