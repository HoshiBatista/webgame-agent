## Завершение, восстановление и ремонт

Повторно проверены обработка уже отправленного ответа до решения по кандидату,
получение receipt после дедлайна новых отправок, запрет повторять неизвестный запрос,
сохранение usage при ошибке схемы/отмене и остановка по лимиту. Нового воспроизведённого
дефекта этого жизненного цикла не найдено. Локальные регрессии включают возобновление
после сбоя, сохранённый ответ и check-only путь без inference.

Ремонт проверен относительно точной выбранной версии. Неизменённые модули защищены,
compact runtime/HTML/CSS не выдаются модели для замены. При неполных checks разрешение
исправлять код связано с актуальным независимым свидетельством дефекта. Check_repair
сохраняет код и требования; новые сценарии не открывают автоматическое принятие.
Старые игровые контракты не восстанавливались; финансовый учёт не удалялся.

Контрольный запуск — ограниченная проверка конкретного наблюдения. Он не доказывает
весь замысел игры, все случайные траектории или качество интерфейса. Для случайных
игр в пилоте дополнительно использован адаптивный оценщик с настоящим вводом;
результат нельзя превращать в универсальное обещание качества модели.

## Совместимость Codex

На настоящем CLI `0.164.0-alpha.11.1` с отдельным временным каталогом **без auth.json**
выполнены только `initialize`, `initialized`, `config/read`, `thread/start`.
Подтверждены точные `gpt-6-sol` / `gameforge_codex`, ephemeral, пустые environments
и runtime roots, read-only, `networkAccess=false`, `approvalPolicy=never` и отключённые
возможности инструментов. Retry limits остаются нулевыми.

Схемы, сгенерированные именно установленным CLI, проверили параметры thread/start
и turn/start; второй метод **не отправлялся**. Использование схем установленной
версии соответствует [документации App Server](https://learn.chatgpt.com/docs/app-server).
Это проверка совместимости протокола, не измерение авторизованной генерации.

**26** тестов Codex с подставным RPC-транспортом прошли, включая четыре full-операции
и восемь compact-комбинаций. Они проверяют схему, единственный turn, отсутствие рабочих
сред, usage и закрытие соединения. Они не выдаются за живую работу CLI с моделью.
Локальная проверка доступности Pro больше не возвращает ошибку версии; авторизация
не копировалась и не менялась.
