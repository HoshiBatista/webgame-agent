# Реализация демонстрационной аналитики — 13.11.2026

Первый выпуск реализован в ветке `feature/game-analytics` от `main@d2a70fd`.
Флаг выключен по умолчанию. Развёртывание и настоящие модельные вызовы не выполнялись.
[Контракт и определения метрик](game-analytics-design.ru.md), [HTTP API](api.md#optional-demonstration-analytics).

## Что работает

- Неизменные версии `AnalyticsDataset`: встроены 96 вымышленных наблюдений по восьми
  аудиториям, только mobile/touch. Импорт атомарен и идемпотентен; изменение прежней
  версии и понижение активной версии отклоняются. Старая версия остаётся в базе.
- Доли завершений и повторов считаются от числа стартов. Активное время имеет
  собственный знаменатель; нули не превращают отсутствие измерений в наблюдения.
  Сравнения используют точные отношения; рекомендациям нужны три семейства и
  достаточное число наблюдений с обеих сторон. Максимум две совместимые идеи.
- Авторизованный read API и необязательный блок в новом чате. Загрузка начинается
  при раскрытии; устаревший ответ другой аудитории игнорируется. Демоисточник подписан.
  Выбор и удаление идей не вызывают модель. При смене аудитории выбор очищается
  с пояснением; текст запроса сохраняется. Общие пожелания не меняются.
- Обычный POST создания принимает только ID набора, hash, версию политики и ID идей.
  Сервер проверяет содержимое и закрепляет точный снимок в Run вместе с outbox.
  ID идеи включает её текст и основание: обновление не подменяет прежний выбор.
- Повтор того же запроса возвращает прежний Run даже при отключённом флаге или
  отозванном наборе. Иной выбор под прежним ключом конфликтует, включая старые ключи
  без профиля модели. Две одновременные отправки создают один Run/outbox.
- Pro plan/create и Lite/compact create получают готовую сохранённую проекцию.
  Отдельной модельной операции аналитики нет. Проверен штатный Lite code → music
  через имитатор relay: два прежних вызова, без третьего вызова аналитики.
- Снимок копируется в Revision, сохраняется при правке, продолжении, повторной
  проверке, восстановлении ответа и ремиксе. Edit/repair/check_repair не получают
  идеи как новую задачу. Worker не перечитывает актуальный набор.
- История различает сохранение, подготовку, отправку, неизвестный исход и полученный
  ответ. Передача идеи не объявляется доказательством её реализации.

## Включение

Сначала обновите приложение обычным способом с резервной копией базы и примените
миграцию `0025_game_analytics`. Старые Run/Revision получают пустой снимок; игровые
исходники и артефакты миграция не переписывает. Данные автоматически не импортируются.

Для уже обновлённой нативной установки:

```sh
.venv/bin/python manage.py migrate
.venv/bin/python manage.py load_demo_analytics
```

Для уже обновлённого Compose:

```sh
docker compose run --rm init
docker compose exec app python manage.py load_demo_analytics
```

Затем установите `GAMEFORGE_ANALYTICS_ENABLED=1` в приватном `.env` и перезапустите
app/worker: `docker compose up -d` либо stop/start через `scripts/dev.py`.
Повтор команды импорта безопасен. Для отключения новых выборов верните флаг в `0`
и перезапустите процессы. История остаётся читаемой; уже закреплённый Run сохраняет
свой контекст. Остановка такого задания выполняется обычной отменой.

## Проверки

Использованы Python 3.12.3 и временная PostgreSQL 18.7, отдельные от рабочей базы.
Сначала применены все миграции на пустой базе и дважды импортирован демонабор.
Собраны sdist/wheel; wheel установлен в отдельное runtime-окружение. Проверено
чтение JSON через `importlib.resources`, построение policy snapshot из установленного
пакета и `pip check` без ошибок. Данные включены в package-data.

Команды из корня репозитория с настроенной тестовой PostgreSQL:

```sh
.venv/bin/pytest tests/test_game_analytics.py studio/tests/test_analytics.py
.venv/bin/pytest -m 'not browser and not native_browser and not live'
.venv/bin/ruff check gameforge studio generation validation scripts tests
.venv/bin/mypy generation validation --ignore-missing-imports
.venv/bin/python manage.py check
.venv/bin/python manage.py makemigrations --check --dry-run
npm run lint --prefix web
npm test --prefix web
npm run build --prefix web
```

Полная серверная регрессия: **1359 passed, 164 deselected**. Интерфейс:
**160 passed**. Ruff, mypy (55 модулей), Django check, соответствие миграций,
ESLint/Prettier и production-сборка прошли. Новые проверки охватывают арифметику,
неверные/устаревшие данные, права/CSRF, гонки, повторную доставку, наследование,
дозавершение и восстановление, ограничения контекста и отсутствие новых операций.

Дополнительно проверен настоящий HTTP-интерфейс в Chromium на 320×720, 390×844,
844×390 и 1440×1000. На каждом размере выбрана идея, выполнено раскрытие/сворачивание
клавиатурой, проверены видимость подписи демоданных и кнопки отправки, отсутствие
горизонтального переполнения страницы и ошибок JS. Искусственный ответ 503 на POST
проверил передачу ID и сохранение текста/выбора. Генерация в этом прогоне блокировалась;
iframe отсутствовал, сгенерированный игровой код не запускался на хосте.
Для низкого экрана уменьшены панель аналитики и поле ввода; сравнение прокручивается.

Один прогретый локальный пакет из десяти параллельных GET дал 10,67–39,35 мс при
96 строках и четырёх HTTP-потоках. Это наблюдение, не production p95 и не проверка
предельных 128 строк. [Факты прогона](evidence/game-analytics-2026-11-13.json),
[телефон](evidence/game-analytics-320.png), [альбомный экран](evidence/game-analytics-844.png).

## Границы доказательств

Демоданные показывают продуктовый путь, а не поведение клиентов. Реальная телеметрия,
A/B-эксперимент и измеренное улучшение удержания не входят в этот выпуск.
Тесты с fake/relay-имитатором подтверждают состав и сохранение отправляемого контекста,
но не следование идеям настоящей моделью. Дополнительный обязательный вызов не добавлен;
возможные ремонты и их расход зависят от будущего результата модели.

Изолированный игровой browser/native_browser-набор здесь не подтверждён: в окружении
нет работающего контейнерного валидатора, нативному браузеру не хватает системных
библиотек. Пробный запуск без фильтра дал `validator_unavailable` и был остановлен;
успех полной регрессии выше относится к явно указанному фильтру. UI-прогон Chromium
не заменяет проверку игрового sandbox или физического телефона/WebView.
Docker-развёртывание и платный сравнительный пилот не выполнялись.
