# Проверка доступного WKWebView

18 октября 2026 года выполнен реальный визуальный smoke в **macOS WKWebView**
на macOS 26.5.2 (25F84). Это дополнительная проверка совместимости экспорта,
а не проверка неизвестного конкурсного WebView и не замена проверок механик.

`scripts/wkwebview-smoke.swift` загружает точные байты экспортированного HTML
в iframe `sandbox="allow-scripts"` без `allow-same-origin`. Внешняя обёртка
принадлежит тесту; игровой исходник не меняется. У WebKit непостоянное хранилище,
нет native API bridge, script message handlers, file URL и файлового base URL.
Внешние запросы запрещены Content Security Policy и WebKit content blocker;
навигация разрешена только на внутренние `about:blank`/`about:srcdoc`.
Перед снимком проверяется, что игровой iframe имеет непрозрачный origin.

Проверены два экспорта:

| Экспорт | Размер viewport | SHA-256 HTML | Результат |
| --- | --- | --- | --- |
| Инфраструктурная fixture | 390×844 | `31f5703a5c0f6a76ffffdb83cc04d6ef731771dc57e6f7c00fc090bbfefb1d9f` | Сцена отрисована; PNG просмотрен |
| Принятые генератором крестики-нолики | 390×844 | `d4955c6fa8aa4ec33c8396e429e98912ed9d4287ee5e8c021034e4a69689b7ff` | Стартовый экран, текст и кнопка отображаются; PNG просмотрен |
| Тот же экспорт крестиков-ноликов | 1024×768 | `d4955c6fa8aa4ec33c8396e429e98912ed9d4287ee5e8c021034e4a69689b7ff` | Стартовый экран отрисован; нижняя часть карточки выходит за первый экран, прокрутка/полный desktop UX не проверялись |

Игра получена из сохранённого результата реальной модели. Исходники игры для
этой проверки вручную не исправлялись. Локальные JSON-отчёты и PNG находятся в
`.data/wkwebview/`; в Git они не включаются. Измеренные размеры заданы в CSS-пикселях,
PNG на Retina имеет больший физический размер.

Воспроизведение на macOS с установленными Xcode Command Line Tools:

```sh
mkdir -p .data/wkwebview .data/swift-cache
xcrun swiftc -module-cache-path .data/swift-cache \
  scripts/wkwebview-smoke.swift -o .data/wkwebview/smoke
.data/wkwebview/smoke \
  --html /absolute/path/to/export.html \
  --out /absolute/path/to/output-prefix \
  --width 390 --height 844
```

Статус `visual_snapshot_created` означает получение изображения из настоящего
WebKit и подтверждение непрозрачного iframe. Для заключения о визуальном качестве
нужно открыть PNG. Скрипт не нажимает игровые кнопки и не объявляет механику
пройденной. Встроенный 30-секундный watchdog относится только к этой одноразовой
утилите; он не ограничивает генерацию. Реальные игровые эффекты отдельно проверяет
контейнерный Chromium. Android WebView, физическое мобильное устройство и
конкурсный хост пока не проверены.
